# 解体工事 販売管理システム(デモ)

総合解体工事業の営業・工事・支払の流れに合わせて設計した、ブラウザで動く販売管理システムです。
転職活動用のポートフォリオとして公開しています。**データはすべて架空です。**

▶ デモ:https://shsuzuki27-afk.github.io/kaitai-sales-system/

## 作った背景

解体工事会社の総務事務として、販売管理システムの導入検討に関わりました。
市販の販売管理システムは物販向けのものが多く、解体工事業に特有の次のような業務に合いにくいという課題がありました。

- 一戸建てなどの小規模解体と、公共工事・RC造などの大規模解体で、営業の進め方や金額規模が大きく違う
- 見積の提出が受注の前提で、問合せ・紹介・入札情報など「見込み客」の段階から追いかけたい
- 請求は工事の進み具合に応じた**出来高請求**、協力業者への支払も**出来高ベース**
- 産業廃棄物の**電子マニフェスト(JWNET・e-reverse)**の登録漏れを防ぎたい
- 電子契約サービスとの連携

これらを1本の業務の流れとしてつなぐことを目標に、要件整理から画面設計・実装まで行いました。
実装には生成AI(Claude)を活用しています。

## 主な機能

| 画面 | 内容 |
|---|---|
| ダッシュボード | 商談中の見込み金額、受注残、今月の出来高請求、協力業者の未払残、粗利見込み、部隊別グラフ、月別請求グラフ、要対応リスト |
| 見込み客・案件 | 顧客・工事名・構造・面積・担当部隊・営業担当・流入経路・受注確度で管理 |
| 見積 | 明細(解体・産廃処分・整地など)と諸経費率で自動計算。よく使う項目から追加。見積書を印刷/PDF保存 |
| 受注工事・電子契約 | 見積から受注登録。工期・出来高・請求済額・協力業者発注額・粗利率を一覧。電子契約の送付/締結状況 |
| 出来高請求 | 累計出来高率を入力すると「契約額 × 累計出来高率 − 前回までの請求額」で今回請求額を自動計算。請求書を印刷/PDF保存 |
| 協力業者・支払 | 工事ごとの発注登録、出来高に応じた支払額の自動計算、支払一覧CSV |
| マニフェスト | 廃棄物の種類・数量・方式・番号・状態を記録。未登録分をダッシュボードに警告し、入力作業用CSVを出力 |
| データ管理 | JSONでのバックアップ/読込、サンプルデータへの初期化 |

## 工夫した点

- **業務の流れでデータをつなぐ**:案件 → 見積 → 受注 → 請求/発注/マニフェストが連動し、見積を受注にすると案件の状態も自動で更新
- **出来高計算の整合性**:累計出来高率は前回より大きい値しか入力できず、請求・支払の取消は最新分のみとして、金額の食い違いを防止
- **「要対応」の自動抽出**:電子契約の未締結、マニフェスト未登録、今月の出来高請求の未作成、見積未作成の見込み客、見積の期限切れを一覧化
- **導入しやすさ**:HTML/CSS/JavaScriptの1ファイルのみ。サーバーやインストールは不要

## 技術

- HTML / CSS / JavaScript(ライブラリ不使用、1ファイル構成)
- データ保存:ブラウザの localStorage(外部への送信なし)
- 公開:GitHub Pages
